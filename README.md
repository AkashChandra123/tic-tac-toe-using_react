# tic-tac-toe-using_react

This project is a modern implementation of the classic **Tic‑Tac‑Toe** game built with **React** and bundled using **Vite**.

## Features
- Interactive gameplay with move history navigation
- Dynamic winner detection and highlighted winning squares
- Scoreboard tracking wins for both players
- Restart button for quick replay
- Clean, responsive UI centered on the screen

## Tech Stack
- React (with Hooks for state management)
- Vite (fast bundler and dev server)
- JavaScript + React Compiler enabled

## Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/AkashChandra123/tic-tac-toe-using_react.git

2. Install dependencies:
    npm install

3. Run the development server:
    npm run dev

4. Open http://localhost:5173 in your browser.

- You can deploy this project easily using  GitHub Pages or Vercel for a live demo link.
